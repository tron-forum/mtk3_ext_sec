# μT-Kernel 3.0 Secure Extension
μT-Kernel 3.0 Secure Extension is software that extends the security functions of μT-Kernel 3.0.  
This extension is integrated into μT-Kernel 3.0 and operates as part of it. This extension supports the TrustZone function of the Arm v8-M architecture.  

μT-Kernel 3.0 Secure Extensionは、μT-Kernel 3.0に対してセキュリティ機能を拡張するソフトウェアです。  
本Extensionは、μT-Kernel 3.0に組み込まれ、その一部として動作します。本Extensionは、Arm v8-MアーキテクチャのTrustZone機能に対応しています。
